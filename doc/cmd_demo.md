# `scripts/cmd_demo.py` — 指令跟踪的量化演示

对应代码：`scripts/cmd_demo.py`。相关教训见 `experience.md` §17、§18；本文只讲抽象结构。

## 职责

给策略喂一串**分段恒定**的横向/旋转指令（段内恒定、段间跳变），边跑边统计
实测响应，最后输出「指令 vs 实测」表与两个聚合指标：最小二乘**斜率**（1.0 = 完全
跟上）与**相关系数**。与 teleop 的区别：teleop 是闭环遥控演示，本脚本是开环
测量工具。

## 核心抽象

### 两套指令表

`INPLACE_PHASES`（原地横移/自转/斜走）与 `WALK_PHASES`（边走边跟），每段按序跑
`--hold-steps` 步。数值都落在课程量程内 —— 量程外的指令测的是外推行为。
开局把 `set_commands` 的量程放开到指令表的最大幅度，否则写入的指令会被采样范围
夹住。

### 为什么用斜率 + 相关系数

**输出常数能把平均绝对误差压到最小**（常数 = 指令分布的均值），所以「误差小」
不构成跟随的证据；斜率衡量响应增益、相关系数衡量「指令变、实测跟着变」。
这套判据与环境侧平地成功判据的 `flat_track_min_corr` 是同一个思想的两处实现。

### 摔倒不中断

段内摔倒就重开一回合，但**继续**按原计划换指令 —— 便于看跨段趋势。
